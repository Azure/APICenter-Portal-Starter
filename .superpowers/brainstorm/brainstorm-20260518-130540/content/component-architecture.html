Proposed Refactored State

Shared types & components
types/evaluation.ts (NEW — base types)
├── EvaluationResult (base: status, overallScore, tiers, updatedOn)
├── EvalTierResult, EvalAssertion, EvalJudgeScore (moved from skillEvaluation.ts)
├── SkillEvaluationResult extends EvaluationResult (+ skillName)
└── AgentEvaluationResult extends EvaluationResult (+ agentName, versionName)

experiences/EvaluationDetails/ (RENAMED — shared)
├── EvaluationDetails.tsx (accepts EvaluationResult)
├── EvalScoreBadge.tsx (unchanged)
├── EvalScoreBar.tsx (unchanged)
├── EvalRadarChart.tsx (unchanged)
├── EvalAssertionList.tsx (unchanged)
└── EvaluationDetails.module.scss (renamed)

hooks/useAgentEvaluationResult.ts (NEW)
└── fetches /agents/{name}/versions/{ver}/evaluationResults/default

mocks/agentEvaluationMocks.ts (NEW)
└── mock data for dev preview (like skills)

Integration Points

SkillInfo.tsx (updated imports)
• Imports from EvaluationDetails/ instead of SkillEvaluation/
• Uses <EvaluationDetails> instead of <SkillEvaluationDetails>
• No behavior changes
AgentInfo.tsx (new assessment tab)
• New useAgentEvaluationResult(name, selectedVersion) hook
• Assessment tab appears when data exists
• Same <EvaluationDetails> component
• Score badge in tab header (like skills)
