Type System Design

Base evaluation types and extensions

types/evaluation.ts

Base Types (shared)
interface EvaluationResult {
  status: 'pass' | 'fail';
  overallScore: number;
  maxScore: number;
  evaluationConfigurationName: string;
  updatedOn: string;
  structuralChecks: EvalTierResult<EvalAssertion>;
  schemaValidation: EvalTierResult<EvalAssertion>;
  qualityAssessment: EvalTierResult<EvalJudgeScore>;
}

interface SkillEvaluationResult extends EvaluationResult {
  skillName: string;
}

interface AgentEvaluationResult extends EvaluationResult {
  agentName: string;
  versionName: string;
}

EvalTierResult, EvalAssertion, EvalJudgeScore, EvalStatus — all move here unchanged.
UI components accept EvaluationResult (base), not the specific extensions.

API Endpoint Mapping

Skill (existing)
GET /skills/{skillName}/evaluationResults/default

Hook: useSkillEvaluationResult(skillName)
Agent (new)
GET /agents/{agentName}/versions/{versionName}/evaluationResults/default

Hook: useAgentEvaluationResult(agentName, versionName)
